# 数据源清单（全免费版）

> 说明：所有来源均为公开页面 / 公开接口 / 免费库，不需要付费 API。标注"待验证"的表示链接或接口可能随平台改版变化，P0 阶段逐一验证。

## Shopee（P0 主攻）

每个市场都有独立的站点和数据，先按用户主做市场做深，再横向复制到其他市场。

### 0. 已实测可用（2026-08-08）

- 类目树接口：`/api/v4/pages/get_category_tree`（印尼 / 马来 / 越南均可用，返回完整多级类目树，含子类目）
- 搜索联想词接口：`/api/v4/search/search_hint?keyword=...`（返回相关热搜词及位置，可每日对比生成涨跌）
- 商品搜索接口：`/api/v4/search/search_items` 已被反爬拦截（403），暂不采用

### 1. 热搜词

- 来源：Shopee 各市场公开热搜词接口 / 搜索下拉关键词（公开接口，按市场域名区分）
- 用途：当日热搜词、热度值、增速 → 选品与标题用词
- 状态：待验证

### 2. 类目热销

- 来源：Shopee 站点类目页（热销商品列表，公开网页）
- 用途：类目树结构、各子类目热销商品、价格、销量排序
- 状态：待验证

### 3. 官方市场周报（如适用）

- 来源：Shopee 卖家中心 / 官方市场周报页（需卖家账号，免费）
- 用途：官方口径的热销类目与趋势
- 状态：待验证

### 4. 卖家中心选品 / 热搜工具（如适用）

- 来源：Shopee 卖家中心内置选品工具（免费，登录可见）
- 用途：类目容量、热搜词等官方数据
- 状态：待验证（需要卖家账号登录，采集可行性需测试）

## Amazon（P2）

- Best Sellers 畅销榜：公开网页，类目覆盖广
- Movers & Shakers 飙升榜：公开网页，约 20 个根类目，每小时更新——最适合"涨跌"信号
- New Releases 新品榜：公开网页
- 参考开源项目：exotic-amazon（全站采集）、global-ecom-skills（飙升榜采集脚本）

## Ozon（P2）

- 公开热销页 / 类目页（ozon.ru）
- "卖什么"搜索词工具页：搜索词热度
- 参考开源项目：ozon-scraper、ozon-search-queries-collector

## Wildberries（P2）

- 公开类目目录与热销接口（wildberries.ru 公开接口）
- 参考开源项目：wildberries-parsers、wildberries-parser-in-python

## 宏观趋势（补充信号，P2+）

- Google Trends（pytrends 免费库）：类目 / 关键词全球需求热度
- TikTok Creative Center（如免费可访问）：短视频带货热点（备用）

## 明确不用（付费源）

知虾、卖家精灵、Sorftime、MPSTATS、极鲸云、Nexscope 等第三方付费 API 本期不接入；后续若免费数据不够用，再评估是否引入。
