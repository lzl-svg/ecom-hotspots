# 数据模型（v1）

> 设计目标：一套统一结构装下所有平台，"每日快照 + 历史对比"支撑涨跌曲线。

## 核心思路

每天定时把每个平台 / 市场的类目、热搜词、热销商品存一份"当日快照"，隔天再存一份，对比前后排名和热度变化，就得到涨跌曲线。

## 表结构

### 1. 平台与市场（platform）

- 平台：Shopee / Amazon / Ozon / WB…
- 市场 / 站点：如 Shopee 台湾、Shopee 马来；Amazon US / DE…
- 字段：平台名、市场码、语言、币种、采集开关

### 2. 类目树（category）

- 字段：平台、市场、类目 ID、父类目 ID、类目层级（1/2/3）、类目名（本地语言 + 中文译名）
- 作用：支撑"类目 → 子类目"下钻

### 3. 每日快照（snapshot）

- 类目快照：日期、类目 ID、排名、商品数、销量 / 搜索量估算、均价、Top 商品清单
- 关键词快照：日期、关键词、热度值、排名
- 商品快照：日期、商品 ID、标题、价格、销量、评分、所在类目
- 每天每个来源一条记录，方便对比

### 4. 趋势指标（trend，由快照自动算出）

- 排名变化（昨日 / 7 日 / 30 日）
- 热度增速（环比、周环比）
- 热度分：排名变化 + 搜索量增速 + 连续上榜天数加权，0-100，用于站点统一排序

## 统一热度分说明

不同平台原始指标不同（Shopee 有搜索热度、Amazon 有销售排名、WB 有销量），不能直接比较。站内统一换算成"热度分"，只用于自己站内排序，不做跨平台绝对比较。

## 存储

- SQLite 单文件（MVP 阶段）
- 数据库文件放项目目录，每日自动更新，网页只读展示
