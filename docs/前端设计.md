# 前端设计（v1）

## 整体风格

- 浅色界面，对照用户 Codex 桌面端（实测配色：白色主背景 #FFFFFF、浅灰面板 #F3F0F1、浅玫瑰色侧边栏底色 #FAF6F7、深色文字）
- 中文界面，操作逻辑人性化：打开就能看懂，点击即下钻，随时能返回
- 图表采用浅色适配配色，涨绿跌红，hover 有详情
- 点缀色使用 Codex 品牌绿 #10A37F（上涨、选中态、Logo）

## 页面结构

### 1. 首页 / 总览

- 顶部：平台切换（默认 Shopee）+ 市场切换（印尼 / 马来 / 越南）
- 中间：今日数据状态条（"数据更新于 08:30 · 已连续更新 23 天"）
- 主体：各市场"类目热点榜"卡片 + "热搜词飙升"卡片

### 2. 类目热点榜

- 表格 / 卡片列表：类目名、热度分、排名变化（↑↓）、7 日增速
- 每个类目可点击展开 → 子类目列表；再点进子类目 → 详情

### 3. 类目详情

- 涨跌曲线（日 / 周 / 月切换）
- 指标卡：热度分、搜索热度、商品数、Top 热销商品
- 热搜词：该类目下相关热搜词及增速
- 面包屑导航：印尼 → 女装 → 连衣裙，可逐级返回

### 4. 热搜词榜

- 当日热搜词 + 排名变化 + 搜索热度趋势小图

### 5. 数据状态页

- 每个市场 / 数据源的最近更新时间、成功 / 失败、断更天数

## 交互原则

- 所有跳转都在站内完成，不用外部链接做核心操作
- 常见操作不超过两步：选平台市场 → 点类目
- 空数据 / 未更新时给出友好提示，而不是空白页
